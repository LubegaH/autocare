# Code review

Review every change against `docs/workflow/code-review-standards.md`. Read changed files in full and report security/data-safety, correctness, tests, simplicity, maintainability, failure UX, plausible performance, and documentation findings in that priority order.

For database or authorization changes, also apply `docs/workflow/security-review-checklist.md` and the tenant-isolation requirements in ADR-0002. No critical finding may remain when work is declared done.
