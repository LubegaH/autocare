# Capture Durable Lessons

Scan the session for mistakes the user corrected, instructions they repeated, lasting decisions, and gotchas that consumed time.

For each useful lesson:

1. Draft the exact text.
2. Choose its destination: `AGENTS.md` conventions or constraints, or the appropriate section of `docs/memory.md`.
3. Confirm that it prevents a repeat rather than recording trivia.
4. Propose removal of stale guidance where applicable.

Append proposals to `docs/pending-learnings.md` and present them. Apply only items the user approves. Keep `AGENTS.md` short; move detail to `docs/` when an addition would bloat it.
